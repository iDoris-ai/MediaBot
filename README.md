# MediaBot

**跑在 Claude Code 上的媒体运营 Agent —— 给没有新媒体运营岗位的个人、社区和小公司。**

开源、免费、自托管。核心模型走 Claude Code CLI，可切换到 Kimi / GLM / DeepSeek 等任意兼容 `ANTHROPIC_BASE_URL` 的后端。

---

## 它解决什么问题

个人、初创团队、小公司通常没有专门的新媒体运营——没有人天天写帖子、做图、发布、回评论、追热点。市面上的开源工具要么只管发布（Postiz、Mixpost），要么只做内容策展（social-media-agent），**没有一个把"内容生成 → 多平台发布 → 互动反馈 → 态势监控"在中文语境下打通**，而且几乎没有工具覆盖小红书/公众号/视频号/抖音。

MediaBot 想做的是把这五步串成一个闭环 Agent：

```
① 目标   你说清楚想要什么（涨粉/涨流量/涨线索），Agent 核实基线、和你商定可验证目标
② 内容   从素材库/抓取的信息生成初稿（图文/短视频脚本）
③ 发布   一次生成，多平台分发（含中文平台）
④ 反馈   自己帖子下的评论/私信，起草回复
⑤ 监控   追踪行业新闻/竞品动态/趋势，供下一轮内容参考
```

## 设计原则

- **Claude Code 原生**：不重新发明一个 agent 运行时，直接跑在 Claude Code（或兼容 CLI）之上，模型可换成 Kimi/GLM/DeepSeek 等任意兼容后端。
- **人工审阅优先**：发布/触达类动作默认需要人过审，监控/研究类动作只读不发（"eyes, not hands"）。
- **中文平台优先**：这是现有开源方案里最大的空白——小红书、公众号、视频号、抖音都没有官方开放发布 API，需要走浏览器自动化（cookie 登录），不是简单调 REST API 能搞定的。
- **Apache-2.0**：完全开源免费，个人/社区/商业公司都能直接用、直接改。
